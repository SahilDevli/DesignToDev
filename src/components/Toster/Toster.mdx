# Toster

A 296×88 toast notification with a white background, a green border and a centered success message. Use it for brief, non-blocking status feedback such as a confirmation after a user action.

<Controls />

## Variants

### Toster

Figma defines one variant: white (`--colors-neutral-100`) background, 4px solid `--colors-tertiary-700` border, 13px radius, centered 24px medium `--colors-tertiary-700` text.

<Canvas of={TosterStories.Default} />

## Usage

```tsx
import { Toster } from '../components/Toster/Toster';

<Toster message="Login Successful!" />
```

## Responsive

- Width stays `296px` with `max-width: 100%`, so it never overflows a narrower parent.
- Height is `min-height: 88px` rather than fixed, so a longer custom `message` wraps instead of being clipped.
- Horizontal padding and font size are fluid (`clamp(...)`), keeping the card readable down to a 375px viewport. The 296px width is unchanged since it already fits every target breakpoint.

## Accessibility

- The root has `role="status"` and `aria-live="polite"` so assistive tech announces the message when the toast mounts.
- Extra attributes such as `aria-label` are passed to the root `<div>` via `...rest`.

## Assumptions

- Figma's absolute text inset is reproduced as flex centering with literal padding, not matching percentages.
- No icon or close control exists in the Figma node, so none is built; a consuming app controls when the toast mounts/unmounts.
- The 296px width is unchanged across breakpoints; only padding and font size are fluid.
- 4px border width, 13px radius and 40px horizontal padding are literal values with no matching design token.
